# Split design

Split is a warm, compact shopping workspace. The cart is the primary product surface. Product photography and participant colors carry the visual personality.

Alex uses lilac (#A68BDC), Jordan uses mint (#75B9AD), and Sam uses peach (#F4AE75). Pair pastel fills with darker text and pair every allocation color with initials, a name, or an amount. Use Inter or the platform's system sans and tabular figures for money and quantity. Use Lucide outline icons and label icon-only actions for assistive technology.

## Surfaces and layout

- Landing pairs the product headline and two entry actions with a compact preview of collaborative shopping. Keep the experience recognizable in the first viewport.
- Desktop uses a constrained two-column layout with a spacious product list and a narrower summary. Keep item thumbnails and amounts aligned across rows. On mobile, stack the layout and keep the checkout action within easy reach.
- Use hairline borders, soft tinted surfaces, roughly 20px panel radii, and circular initials. Let totals and state changes carry visual emphasis.
- The allocation editor pairs three methods with participant controls, exact amounts, and a segmented bar. Place custom amount validation near the inputs. Give all interactive controls a visible keyboard focus state.
- Keep review, completion, and receipt consistent with the cart. Indicate demo status in checkout and on the receipt. Use the group total as the receipt's visual anchor.
- Use 150–250 ms transitions for interactive changes. Respect reduced-motion preferences and preserve the same status information when animation is disabled.
